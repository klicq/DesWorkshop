Orbit2026
Explore the case study +

Self-initiated concept · Fictional brief

The brief

Help a developer-first API platform explain its value to both engineering teams and buyers. Extend an existing identity across a product launch without introducing a second visual language.

The decisions

I built the story around one idea: give teams room to build. A branching route motif connects services without suggesting that an API is a physical cable. A product specialist would review each diagram before release.

In Figma, I defined headline lengths, spacing tokens, accessible colour pairs and flexible campaign components. Claude artifacts helped explore responsive layouts; Claude Code handled repetitive exports and prototype scaffolding, with visual review at each step.

The delivery

A responsive landing-page concept, six paid-social layouts, a HubSpot email module and a reusable 12-slide sales-deck system. The handoff specifies asset names, image compression, alt text and CMS content limits.

What I’d measure

Qualified demo requests and landing-page engagement, using an agreed event plan in Google Analytics. This is concept work, so no conversion uplift or client outcome is claimed.

Fieldguide2025
Explore the case study +

Self-initiated concept · Fictional brief

The brief

Turn a dense API onboarding manuscript into an approachable reference for developers and product managers. The same publication needs to work as a downloadable ebook and a printed event giveaway.

The decisions

I organised the sample content around tasks: authenticate a request, apply a rate limit and understand an error. A repeatable visual grammar separates actors, requests and responses. Labels carry the meaning so diagrams never depend on colour alone.

A modular page grid accommodates code samples, wide diagrams and short summaries. A draft would go through a technical accuracy review, followed by a screen-reader and reading-order check on the final tagged PDF.

The delivery

A 32-page sample publication system, eight diagram templates, ebook cover variants and a print specification. Production notes cover CMYK conversion, 3 mm bleed, embedded fonts, image resolution and a supplier-approved proof before printing.

The next iteration

Test whether readers can find the authentication example and explain the rate-limit diagram without help. Revise confusing labels before expanding the guide into a series.

Assemble2024
Explore the case study +

Self-initiated concept · Fictional brief

The brief

Give a distributed developer community a recognisable meeting place. Create an event identity that stays legible on booth banners, badges, stage slides and social announcements.

The decisions

The joining-brackets motif turns the act of assembling into a flexible identity. Oversized type makes destinations readable at a distance. Speaker names stay editable in shared templates, so late schedule changes do not require a full redesign.

The motion study brings two brackets together to frame the event’s message. A quick entrance leads into a readable hold. The silent prototype below establishes the pacing for an editable After Effects template and a Premiere Pro event edit.

Silent motion study. On-screen text: “assemble — Ideas connect here. Bristol · 18–19 September.”

The delivery

Key visual, exhibition-wall concept, two banner formats, wayfinding posters, badges and a slide-deck kit. The supplier handoff specifies scale, safe areas, colour references, finishing and approval ownership.

How I’d work

A shared request board prioritises print deadlines first. Weekly asynchronous reviews keep marketing, event operations and the print partner aligned, with a documented final sign-off before files reach production.
